Permission boundary

Read-only campaign evidence

AdsForecast requests the advertising read scope. It does not publish ads, change campaign state or edit budgets.

  • Spend and delivery metrics
  • Attributed purchases and purchase value
  • Campaign names and identifiers
Credential boundary

Token stays server-side

The Meta access token is encrypted before storage and is never returned to product JavaScript or browser storage.

  • OAuth state is signed and time-bounded
  • Workspace access is checked per request
  • Connection failures never reveal secrets
Reporting boundary

No silent demo fallback

If live Meta data cannot be loaded, the product shows a clear unavailable state instead of mixing sample rows into the account.

  • Live and demo modes stay separated
  • Latest sync status remains visible
  • Profit remains a modeled estimate
